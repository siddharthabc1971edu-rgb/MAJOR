## Reproducibility

```powershell
python run_experiment.py --mode full --output artifacts
python paper\generate_figures.py
python paper\validate_tex.py
```

Compile with IEEEtran, e.g. `pdflatex ieee_paper.tex` twice (no external `.bib`
file is needed; references use `thebibliography`). A TeX distribution was not
available in this environment, so `validate_tex.py` performs static checks of
braces, environments, citations/labels, table column counts, and figure paths.
